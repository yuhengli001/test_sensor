--- ppt/slides/slide22.xml ---
Vital Signs Processing Pipeline
Processing Logic
Uses unwrapped phase from the locked range bin as input
Applies high-pass filtering to remove slow drift
Separates respiration and heartbeat into different frequency bands
Uses LMS adaptive cancellation to reduce breathing interference
Stores filtered samples for later FFT-based BPM estimation
22

--- ppt/slides/slide23.xml ---
Vital Signs Processing Pipeline
Vital Signs Processing Code
This code processes the unwrapped phase signal
from the locked radar range bin.
apply_hp()
 removes slow drift and DC offset from the phase signal.
apply_butterworth_b()
 
extracts the respiration component in the lower frequency band.
LMS adaptive cancellation is used to reduce breathing interference before heart-rate extraction.
apply_butterworth_h()
 
extracts the heartbeat component in the higher frequency band.
The filtered signals are stored for later FFT-based BPM estimation.

--- ppt/slides/slide24.xml ---
FFT and Output Stabilisation
Output Stabilisation
Apply Hamming window before FFT to reduce spectral leakage
Use zero-padding to improve frequency resolution
Smooth PSD values to reduce frame-to-frame noise
Use Gaussian peak interpolation for more accurate peak frequency estimation
Apply frequency tracking and 5-sample median filtering to stabilise BPM output

--- ppt/slides/slide25.xml ---
Fall Detection Design
Design Logic（
Prototype
 
only
）
Detect a possible fall using motion intensity
Store the pre-fall subject distance
Enter a suspected state after sustained impact
Confirm a fall if the subject remains displaced for a set period
Cancel the suspected state if the subject recovers, moves strongly, or times out

Fresnel Zone Plate (FZP)
FZP: Ladder structure, thickness does not increase with radius
Traditional lenses: thicker with larger aperture → Injection defects (shrinkage marks)
FZP advantages: flat, easy to manufacture, suitable for compact equipment

--- ppt/slides/slide36.xml ---
Conclusion
 
Core Achievement:
Full-Stack Integration: Successful development of an end-to-end 60 GHz 
mmWave
 radar platform (Hardware, Firmware, and iOS App).
Ultra-Low Power: Achieved < 1 µA idle current through hardware power gating and RTOS-based task scheduling.
High-Precision DSP: Validated multiple sensing modes
Range Enhancement: Doubled the stable sensing distance (from 0.3m to 0.6m) using a custom 3D-printed FZP dielectric lens.
